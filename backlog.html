Load your real library
  1. Get a Steam Web API key at steamcommunity.com/dev/apikey. Any domain name works for the form.
  2. Make your game details public. In Steam, open your profile's privacy settings and set Game details to Public. The API returns an empty library otherwise.
  3. Optional: install the HowLongToBeat helper so games get length estimates.
    pip install --user howlongtobeatpy
  4. Run the exporter (steam_backlog_export.py from the project repository). Add --details for genres, Metacritic and controller support. That first run is slower because of Steam's store rate limit. Everything is cached, so later runs only fetch new games.
    STEAM_API_KEY=your_key python3 steam_backlog_export.py --profile https://steamcommunity.com/id/yourname/ --details
  5. Choose Load export and pick steam_backlog.json. The library is saved with this page, so it loads automatically next time. Re-run the exporter and load again whenever you buy a bundle.
