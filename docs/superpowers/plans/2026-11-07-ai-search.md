# AI search ("Ask") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a cost-capped, read-only Claude "Ask" search at `/ask` to steam-backlog-triage, matching Cookbook's and Matinee's Ask.

**Architecture:** Three new stdlib modules. `backlog_query.py` is the read layer, parity-tested against `backlog.html` under node. `access_jwt.py` verifies Cloudflare Access JWTs. `ask.py` holds the settings, gate, tool loop and log. `backlog_server.py` gains `/ask`, `GET /api/ask/status` and `POST /api/ask`. `backlog.html` gains a third mode (`ask`), a header pill, a thread view, and a row renderer factored out of `renderList()`.

**Tech Stack:** Python 3.11+ standard library only (`urllib`, `hmac`, `hashlib`, `http.server`), vanilla JS in the single `backlog.html`, `unittest`, node (parity), the openssl CLI (JWT tests), Playwright 1.49.1 (browser tests).

**Spec:** `docs/superpowers/specs/2026-11-07-ai-search-design.md`. Read it before any task; section numbers below (§n) refer to it.

## Global Constraints

- Python standard library only in product code; `backlog.html` stays one file with no build step.
- `API_VERSION` stays `"2"`; existing routes, responses and the list view's HTML output are unchanged.
- Never commit IPs, hostnames, a real domain, container IDs, a time zone, a real SteamID, real names, personal emails, keys, or a Cloudflare team name or AUD. Placeholders only: `7656119XXXXXXXXXX`, `steam.example.com`, `your-team.cloudflareaccess.com`, emails `@example.com`. Run `python3 .github/scripts/privacy_scan.py` and grep the diff before every commit.
- Commit author: `git -c user.name=SDNick484 -c user.email=SDNick484@users.noreply.github.com commit …`; message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Branch `feature/ask`; commits C1–C5 in this order, each with its tests and the whole suite passing.
- Never call api.anthropic.com from a test or a manual check; `ask.messages_api` is always replaced.
- Defaults: model `claude-haiku-5-5`, daily limit 200, 5 rounds, 5 questions, 60 s budget, 25 s per call, `max_tokens` 2048, tool result 12,000 characters, 40,000-input-token ceiling, `q` ≤ 500, `a` ≤ 1,000, answer ≤ 600, 12 items, 2 in flight.
- The key never reaches `os.environ`, a log line, an error body, the browser or the export child.
- Test switches: `REQUIRE_NODE=1`, `REQUIRE_OPENSSL=1`, `REQUIRE_BROWSER=1` turn skips into failures.

## Review Focus

1. **A library with no export yet** (`steam_backlog.json` missing). Ask should answer "No library export on the server yet." through the model with no 500. → test `test_no_library_tool_error` in Task 3.
2. **The library replaced mid-question** (a Refresh finishing between rounds). The snapshot is taken once, so names still resolve and nothing crashes. → test `test_snapshot_fixed_per_question` in Task 3.
3. **Unicode publisher names** (`™`, `®`, full-width forms, accents). Python's `name_key` must equal the page's `nameKey`. → test `test_name_key_unicode` in Task 1.
4. **Mixed-case or whitespace emails in `ASK_EMAILS` and the token.** They should match case-insensitively. → test `test_email_case_and_spaces` in Task 2.
5. **IPv6 LAN clients** (`::1`, `fd00::/8`, `[::1]:8484` as Host). They count as LAN like IPv4. → test `test_lan_ipv6` in Task 3.

- [ ] **Step 3: Implement `Verifier`** per spec §6. The JWKS cache is a dict `kid → (n, e)` with a fetch time, under a `threading.Lock`. A failed fetch logs to stderr at most once a minute. The signature check:

```python
k = (n.bit_length() + 7) // 8
if len(sig) != k: fail("sig")
em = pow(int.from_bytes(sig, "big"), e, n).to_bytes(k, "big")
t = DIGEST_INFO_SHA256 + hashlib.sha256(signing_input).digest()
want = b"\x00\x01" + b"\xff" * (k - len(t) - 3) + b"\x00" + t
if k - len(t) - 3 < 8 or not hmac.compare_digest(em, want): fail("sig")
```
